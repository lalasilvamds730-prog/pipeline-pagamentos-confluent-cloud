# Evidências do Projeto

Esta pasta reunirá as evidências reais da implementação e dos testes do pipeline de pagamentos em tempo real.

Poderão ser incluídas capturas de tela, resultados de consultas, eventos recebidos e registros de validação das etapas.

As evidências serão adicionadas conforme cada etapa for executada. Nenhuma evidência será considerada concluída antes da validação correspondente.
